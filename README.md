### Hello, I'm Sujair 👋

I build AI systems that help people work with knowledge: agents that collaborate, research tools that make documents useful, and models grounded in real problems. My recent work explores multi-agent reinforcement learning, retrieval-augmented generation, and natural language processing.

### Selected work

| Project | What it explores |
| :--- | :--- |
| **[REMARL](https://github.com/sujairibrahim/REMARL_Thesis)** | Multi-agent requirements engineering with PPO policies that learn how agents choose their next action. |
| **[Research Companion](https://github.com/sujairibrahim/Research-Companion)** | A local-first assistant for searching and asking questions across PDF collections, with answers tied to source documents. |
| **[Grownius](https://github.com/sujairibrahim/Grownius-RAG)** | An agriculture-focused chatbot using retrieval-augmented generation to provide domain-specific knowledge. |
| **[Phrasal Verb Meaning Detection](https://github.com/sujairibrahim/Semantic_Analysis-Phrasal_Verbs)** | NLP experiments and transformer fine-tuning for understanding phrasal verbs in context. |
